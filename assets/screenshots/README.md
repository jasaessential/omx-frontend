# PWA Screenshots

Required for Play Store listing via PWABuilder.

## Required Files

| File | Size | Form Factor |
|------|------|-------------|
| screenshot-mobile.png | 390×844 | narrow (phone) |
| screenshot-desktop.png | 1280×800 | wide (desktop/tablet) |

## Tips
- Take actual screenshots of your app running in the browser
- Mobile: use Chrome DevTools device emulation (390×844 = iPhone 14 size)
- Desktop: use a 1280×800 browser window
- Screenshots appear on your Play Store listing page
